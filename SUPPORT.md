# 支持与反馈 / Support

中文：授权、购买、私密错误报告及第三方源码请求请联系 [asenjoaupa@gmail.com](mailto:asenjoaupa@gmail.com)。普通问题可使用本仓库 Issues。请提供版本、安装包文件名、操作系统、校验结果、复现步骤与脱敏错误。不上传 `.lic`、机器指纹、密钥、个人聊天或客户工程。反馈不自动构成支持时效承诺。

English: Contact [asenjoaupa@gmail.com](mailto:asenjoaupa@gmail.com) for licensing, purchase inquiries, private reports, and third-party source requests. Use repository Issues for ordinary questions. Include the version, package filename, operating system, hash verification, reproduction steps, and redacted errors. Never upload `.lic` files, device fingerprints, secrets, personal conversations, or customer projects. Reporting does not itself create a support service-level commitment.
